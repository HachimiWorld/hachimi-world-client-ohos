# Material Symbols

Source: https://github.com/google/material-design-icons/tree/master/symbols/android
Catalog: https://fonts.google.com/icons

Google Material Symbols, licensed under Apache-2.0 (see LICENSE).
Downloaded XML vectors live in composeApp/src/commonMain/composeResources/drawable/ms_*.xml.
Style: Material Symbols Outlined, weight 400, grade 0, optical size 24; filled except FavoriteBorder.
Android theme tint is removed and the path fill is literal black; Compose Icon controls tint.
Auto-mirroring is enabled for the previously AutoMirrored icons (and the shared ArrowBack resource).
Load with org.jetbrains.compose.resources.vectorResource(Res.drawable.ms_name) in composable code.
Resources are bundled with the app; no runtime download or icon font is required.
